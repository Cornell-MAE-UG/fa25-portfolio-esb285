## Project Overview

### Objectives
As part of a larger club project to build a fully animatronic axolotl, I was individually responsible for designing the tail mechanism, which needed to move both side to side and up when connected to motors.

### Process

I used an octopus 3D model as inspiration for the tail's structure, designing a series of linked members that allowed for flexible, multi-directional motion similar to a real tentacle or tail. Using Fusion 360, I modeled the tail with holes built into each segment to route string, which would be wound by gear motors to actuate the tail's movement. I then 3D printed a prototype to test the mechanism's range of motion and fit.

### Outcomes

The prototype successfully achieved two-axis motion, side-to-side and vertical, validating the linked-member design and string-and-gear-motor actuation approach inspired by octopus tentacle mechanics. However, the 3D printing process revealed tolerance issues with the string holes, which informed adjustments to hole sizing and placement for future iterations. Overall, the project translated the CAD model into a functional physical mechanism that integrated into the club's larger animatronic axolotl build.
